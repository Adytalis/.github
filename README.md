# Adytalis/.github

This repository holds the Adytalis organisation's public profile.

| File | What it does |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The page shown at [github.com/Adytalis](https://github.com/Adytalis) |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Default issue forms (Bug, Feature, Task) for Adytalis repositories without their own |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull request template |
| [`SECURITY.md`](SECURITY.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default community files, shown on any Adytalis repository that has none of its own |
